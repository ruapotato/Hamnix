# Historical notes

Point-in-time audits, gap analyses and status reports, kept for the
record and moved out of `docs/` at the 1.0 tag.

**These are snapshots, not documentation.** Every file here was accurate
on the date in its name and has not been maintained since. Several
describe problems that were subsequently fixed, and at least one
("browser open list") sent work to re-implement things that already
existed. Read them as history; check the tree before acting on anything
they say.
