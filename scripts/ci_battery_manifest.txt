# scripts/ci_battery_manifest.txt — the bare-metal regression battery.
#
# One gate invocation per line, in shortest-first order. The CI job
# 'hamnix-bare-metal' round-robin-shards this list across a matrix of
# parallel runners (index % NSHARDS), so all gates keep running on every
# push but each shard finishes well under its timeout — 56 pure-TCG QEMU
# boots serially blew past the 40-min budget (~75 min needed) and the
# whole battery went permanently red, providing ZERO signal. Add a gate:
# drop a line here (order = fast→slow keeps shards balanced under round-
# robin). Wrapped gates (ci_run_gate.sh) emit the three-valued verdict
# (INCONCLUSIVE→warning on a TCG-starved runner); direct ones are hard
# PASS/FAIL. Blank lines and # comments are ignored.

# FIRST, and ~1 s: the stale-artifact canary. No QEMU. Fails when any tracked

# makes every downstream verdict describe the WRONG build — the 2026-07-24
# office-suite false negative), or when a gate reuses a prebuilt artifact

# test_de_stress_soak: the 30-MINUTE DESKTOP SOAK — open a bunch of apps,
# close a bunch of apps, repeat, and prove the session recovers its RAM.
# NOT FOR THE PER-SHARD BUDGET: this gate runs SOAK_MINUTES (default 30) of
# continuous open/close churn plus ~4 min of boot/teardown, which alone would
# blow the 50-min shard cap that the whole round-robin sharding scheme exists
# to respect. It is therefore gated on HAMNIX_SOAK=1 and is a NO-OP in the
# normal battery; run it nightly, or by hand, or before a release.
#
# What only a soak can see: scripts/test_de_open_close_cycles.sh proves ONE
# open/close cycle works and scripts/test_de_app_churn.sh proves a burst of
# launches maps windows, but a leak of a few hundred KiB per app-close is
# inside boot noise at 24 cycles and fatal over a working day. This gate
# measures the REGRESSION SLOPE of MemFree / PagesInUse / VmaNodesLive /
# KmallocLive / TasksLive / live-wid-count against cycle number, sampled with
# apps OPEN and again with apps CLOSED, and fails on a bad-direction drift
# beyond tolerance — plus wid-table exhaustion (32 slots), task-slot
# exhaustion, unexpected code=143 exits, kernel faults and a wedged console.
# It BUILDS the image rather than warning about staleness: 30 minutes of soak
# against a stale image is 30 minutes of confident nonsense.
[ "${HAMNIX_SOAK:-0}" = "1" ] && bash scripts/test_de_stress_soak.sh || true
