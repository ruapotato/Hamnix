# scripts/ci_ondemand_baseline.txt — the INVENTORY of gate scripts that exist
# in the tree but that no CI job runs, as counted on 55c842b9.
#
# READ scripts/test_gate_registration.sh FIRST. That gate enforces the rule
# this file is an exception to: every scripts/test_*.sh must be registered in
# scripts/ci_battery_manifest.txt, run by a .github/workflows/*.yml step, or
# carry the words "not in ci_battery_manifest.txt because <reason>" in its
# header.
#
# WHY A BASELINE EXISTS AT ALL
# ============================
# 1495 test_*.sh existed on 55c842b9; 528 were in the battery manifest and a
# further ~97 were run by ci.yml (the test_opt_* / test_compiler_* globs and
# the explicit host-gate steps). 879 were run by NOTHING. That is not a state
# one commit can honestly fix: the bare-metal battery is 12-way sharded under
# a 50-minute cap, so blanket registration would blow the cap and turn the
# whole battery red — which is how this repo lost battery signal once already
# (docs/ci_status_2026-07-25.md).
#
# So the 879 are FROZEN here, classified, and the rule is enforced going
# forward. This file is a RATCHET, not an amnesty:
#
#   * A NEW gate may NEVER be added to this list. New gates get registered or
#     annotated; test_gate_registration.sh tells you so in the failure text.
#   * An entry that becomes registered or annotated MUST be deleted from here
#     (test_gate_registration.sh PART 2 fails until it is).
#   * An entry naming a deleted script MUST be deleted from here (PART 2).
#
# The category comment on each line is the on-demand rationale, recorded so
# the next reader can tell DELIBERATE from FORGOTTEN without re-deriving it:
#
#   qemu-boot   transitively launches qemu-system/OVMF. A pure-TCG boot is
#               minutes; 56 of them once blew a 40-minute shard budget. These
#               are on-demand by design — run them for the subsystem you are
#               touching, or promote one into the manifest with a measured
#               runtime.
#   heavy-build rebuilds the kernel / initramfs / installer image (or shells
#               out to debootstrap) without booting. Minutes of build, and it
#               mutates tracked artifacts (fs/initramfs_blob.S), so it is not
#               safe to run concurrently inside a sharded battery.
#   host-cheap  QEMU-free, seconds. THESE ARE THE PROMOTION CANDIDATES. Each
#               one still here is either (a) currently RED on main — see the
#               triage in the commit that introduced this file; registering a
#               red gate poisons the battery — or (b) not yet measured. Do
#               not register one without running it first.
